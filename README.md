# Telegram Bot

Простой Telegram бот на Python.

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` и добавьте в него токен бота:
```
BOT_TOKEN=ваш_токен_бота
```

3. Запустите бота:
```bash
python bot.py
```

## Развертывание на сервере

### Вариант 1: PythonAnywhere (бесплатно)
1. Создайте аккаунт на [PythonAnywhere](https://www.pythonanywhere.com)
2. Загрузите файлы бота через веб-интерфейс
3. Создайте веб-приложение и настройте его на запуск вашего бота
4. Добавьте задачу в планировщик для автоматического запуска

### Вариант 2: VPS (например, DigitalOcean)
1. Создайте сервер (например, Ubuntu)
2. Установите Python и необходимые зависимости
3. Загрузите файлы бота через SFTP или Git
4. Запустите бота через systemd или supervisor

## Доступные команды
- `/start` - Начать работу с ботом
- `/help` - Показать список команд
- `/info` - Информация о боте
- `/echo [текст]` - Повторить ваш текст
